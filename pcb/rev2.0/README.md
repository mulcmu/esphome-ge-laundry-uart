# PCB Rev 2.0

Rev 2.0 reworked the board for automated assembly and adopted an ESP32-C3 module and pinout compatible with the project direction at the time.

> [!WARNING]
> The RX and TX silkscreen labels are swapped. U1 can cause ESP32 boot loops. This revision is retained for history and is not the recommended starting point for a new order.
