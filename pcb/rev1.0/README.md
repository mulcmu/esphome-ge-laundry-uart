# PCB Rev 1.0

Rev 1.0 added three resistor positions so inverted GEA2 serial signaling could be configured with pull-up or pull-down resistors.

This is a historical release. The active tree retains only the original [Gerber archive](manufacturing/GERBER-OnionStraws-rev1.0.zip); editable design files remain available through Git history.
